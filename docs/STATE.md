## Gotchas found while building Phase 0

Each cost real time. They are recorded so nobody rediscovers them.

| Trap | Detail |
|---|---|
| **`.gitattributes` multi-pattern lines are silently invalid** | `*.png *.jpg binary` produces "not a valid attribute name" and **does not fail the commit** — the rules simply never applied. One pattern per line. |
| **`core.autocrlf=true` at SYSTEM level** | Set by the Git for Windows installer. Would corrupt golden files and make normalizer tests fail for reasons unrelated to code. Fixed repo-locally; `preflight` now checks it and reports it as a BLOCKER. |
| **`ServeMux` returns `text/plain` 404s** | Broke the error contract and gave routing 404s a different shape from cross-tenant 404s — an oracle for probing ids. Every service now mounts `httpx.NotFound`. |
| **`-race` requires cgo** | No gcc on this machine, so `CGO_ENABLED=0` and `-race` refuses to run. `task test` skips it on Windows; **CI's ubuntu job always runs it**. |
| **Context keys compare by type** | `obs` and `errs` each defining their own key type made request ids mutually invisible. Hence `platform/ctxkey`. |
| **gosec G101 flags the error taxonomy** | `AUTH_TOKEN_EXPIRED` trips the hardcoded-credential heuristic. Excluded for that one file, by path and rule. |
| **N818** | Python exception classes must end in `Error`; renamed `EngineUnavailable` → `EngineUnavailableError` etc. |
| **Forward references in specs** | Docs correctly name files a later phase creates. `docs/.forward-refs` declares them so the linter stays strict about everything else. |
